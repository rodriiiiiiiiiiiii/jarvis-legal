Política de privacidad de Jarvis

Jarvis es una aplicación personal de un único usuario, su autor. No tiene usuarios externos ni se ofrece al público.

Datos de Google a los que accede

  • El email de las cuentas de Google que el usuario conecta.
  • La lista de calendarios de esas cuentas.
  • Los eventos de esos calendarios, para mostrarlos, crearlos, editarlos y borrarlos.

Uso de los datos

Los datos se usan solo para mostrar y gestionar el calendario dentro de Jarvis. No se venden, no se comparten con terceros y no se usan para publicidad. Los eventos no se almacenan: se piden a Google cada vez que hacen falta.

Almacenamiento

Los tokens de acceso de Google se guardan solo en el servidor de la aplicación (Supabase) y nunca se envían al dispositivo.

Revocar el acceso

El acceso se puede retirar en cualquier momento desconectando la cuenta en Jarvis o desde myaccount.google.com/permissions.

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
